13.1

KEY LANGUAGE TALKING ABOUT THE WEATHER날씨에 대해 말하기

날씨를 물을 때는 “What’s the weather like?” 라고 말해요. 대답할 때는 to be 동사와 알맞은 날씨 단어나 표현을 써요.

What’s the weather like?
Okay, but there are a lot of clouds. It’s cloudy.
💡 like 는 “좋아하다”가 아니에요 여기서 like 는 동사가 아니라 전치사로 “~ 같은”이라는 뜻이에요. I like music. 의 like(좋아하다)와 달라요. → 날씨가 어떠니?
💡 a lot of + 명사 구름의 양을 말할 때는 a lot of 를 명사 앞에 써요. There are a lot of clouds. (셀 수 있는 명사 → are) / There’s a lot of fog. (셀 수 없는 명사 → is)

💡 지금 내리는 비 · 눈 지금 일어나고 있는 날씨는 현재진행형으로 말해요: It’s raining. (비가 오고 있어요) · It’s snowing. (눈이 오고 있어요). 형용사로는 It’s rainy. / It’s snowy.

13.5

KEY LANGUAGE THE TEMPERATURE기온 말하기

기온은 화씨 “Fahrenheit (°F)” 또는 섭씨 “Celsius (°C)” 로 말해요. 말할 때는 to be 동사와 기온 표현을 써서 얼마나 덥고 추운지 말해요.

How hot is it?

How cold is it?
💡 TIP 미국 영어에서는 주로 화씨(°F), 영국 영어에서는 주로 섭씨(°C) 를 써요. 한국은 섭씨를 써요.
32°F = 0°C · 50°F = 10°C · 80°F ≈ 27°C · 100°F ≈ 38°C
boiling = “아주 더운” · freezing = “아주 추운” (구어 표현)
