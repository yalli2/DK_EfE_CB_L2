OVERVIEW 현재진행형 한눈에 보기“지금 이 순간” 일어나고 있는 일을 말할 때

현재진행형(present continuous) = be동사 + 동사-ing. “지금 ~하고 있다 / 지금 ~를 입고 있다”는 뜻이에요.

현재 단순(위): 늘 반복되는 일  |  현재진행(아래): 바로 지금 이 순간
3.1

KEY LANGUAGE THE PRESENT CONTINUOUS현재진행형 — 지금 입고 있는 것, 하고 있는 일

Julie doesn’t usually wear dresses, but today she is wearing a bright red dress.
① doesn’t usually wear = 현재 단순
평소에 늘 하는 일(습관). “보통은 원피스를 입지 않아요.”
② is wearing = 현재진행
지금 이 순간 하고 있는 일. “오늘은 (지금) 빨간 원피스를 입고 있어요.”
3.2

HOW TO FORM THE PRESENT CONTINUOUS만드는 방법 — be동사 + 동사원형-ing (현재분사)

“to be” 의 알맞은 형태(am / is / are)에 동사 + -ing 를 붙여요. 주어와 동사를 바꿔 보세요.

✍️ -ing 붙이는 철자 규칙

규칙방법예
① 대부분+ ingwalk → walking · wash → washing · play → playing · listen → listening · visit → visiting
② -e 로 끝나면e 를 빼고 + inguse → using · come → coming · have → having · relax → relaxing (x 로 끝나도 겹치지 않아요)
③ 한 음절 · 자음+모음+자음 (CVC)마지막 자음을 한 번 더 + ingcut → cutting · sit → sitting · run → running · win → winning
(w · x · y 로 끝나면 겹치지 않아요: playing, fixing, snowing)
④ -ie 로 끝나면 (참고)ie → yinglie → lying · die → dying

🧪 직접 해 보기 — 동사를 입력하면 -ing 형태와 규칙을 알려 줘요

KEY LANGUAGE THE PRESENT CONTINUOUS NEGATIVE현재진행형 부정문 — be동사 뒤에 not

He is wearing a tie, but he isn’t wearing a hat.

부정문은 be동사 뒤에 not. 동사는 그대로 -ing 형태를 유지해요.

be + not + 동사-ing — “is not = isn’t”, “are not = aren’t”
