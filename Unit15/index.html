OVERVIEW 비교급 한눈에 보기두 가지를 비교할 때: 비교급 + than

두 사람 · 장소 · 물건을 비교할 때는 비교급 형용사를 쓰고, 그 뒤에 than(~보다)을 붙여요.

짧은 형용사 → -er than / 긴 형용사 → more ~ than
15.1

KEY LANGUAGE COMPARATIVE ADJECTIVES비교급 형용사

1~2음절 형용사는 대부분 끝에 -er 를 붙여 비교급을 만들어요. 비교하는 대상 앞에는 than 을 써요.

🏖️
Greece is warm.

Greece is warmer than France.
① -er 형용사 끝에 -er 를 붙여 비교급을 만들어요. warm → warmer
② than 비교급 뒤에 than 을 써요. warmer than France (프랑스보다 더 따뜻한)

KEY LANGUAGE FORMING COMPARATIVES비교급 만드는 규칙 — e, y, 자음으로 끝나는 형용사

형용사 끝규칙예
대부분-er 을 붙여요fast → faster
-e 로 끝남-r 만 붙여요close → closer
자음 + yy 를 빼고 -ierearly → earlier
자음 + 모음 + 자음 (1음절)마지막 자음을 한 번 더 쓰고 -erbig → bigger

15.6

KEY LANGUAGE COMPARATIVES WITH LONG ADJECTIVES긴 형용사의 비교급

일부 2음절 형용사와 3음절 이상의 긴 형용사는 -er 를 붙이지 않고, 앞에 more, 뒤에 than 을 써요.

🏝️
This beach is beautiful.

This beach is more beautiful than that one.
🔢 음절 세기 beau · ti · ful → 3음절이라 more beautiful (✘ beautifuller)
👉 that one 앞에 나온 명사(beach)를 반복하지 않고 that one(저것)으로 바꿔 말해요.
