OVERVIEW 날씨 어휘 한눈에 보기명사(sun) → 형용사(sunny) 로 바꿔 날씨를 말해요

이 단원에서는 날씨(weather) 를 나타내는 단어를 배워요. 대부분의 날씨 명사는 끝에 -y 를 붙이면 형용사가 되고, It’s + 형용사 로 오늘 날씨를 말할 수 있어요.

sun → sunny · rain → rainy · snow → snowy — It’s sunny today!
12.1

VOCABULARY WEATHER날씨 — 카드를 누르면 소리가 나요

☁️ 하늘과 비 · 눈

🌪️ 바람과 폭풍

🌡️ 기온

💡 기온 단어 순서 freezing(몹시 추운) < cold(추운) < warm(따뜻한) < hot(더운) < boiling(찌는 듯이 더운). 말할 때 boiling 은 “아주 덥다”, freezing 은 “아주 춥다”는 뜻이에요.

🌈 그 밖의 날씨 단어

✍️ 참고 hurricane / typhoon / cyclone 은 같은 종류의 열대성 폭풍이에요. 대서양은 hurricane, 태평양 서쪽(한국·일본)은 typhoon(태풍), 인도양은 cyclone 이라고 불러요. gray sky(미국) = grey sky(영국).
12.2

VOCABULARY WEATHER ADJECTIVES날씨 형용사 — 명사에 -y 를 붙여요

규칙예
대부분 + ycloud → cloudy · rain → rainy · snow → snowy · frost → frosty · wind → windy · storm → stormy · thunder → thundery
짧은 단어(자음+모음+자음) → 끝 자음 하나 더 + ysun → sunny · fog → foggy
e 로 끝나면 e 를 빼고 + yice → icy
💡 문장으로 It’s sunny. 맑아요. · It’s foggy. 안개가 꼈어요. · It’s windy. 바람이 불어요. 명사는 There’s a lot of fog. 처럼 써요.
